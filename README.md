# OpenPix 🎨

Generate images via [OpenRouter](https://openrouter.ai/) API with multiple AI models.

## Features

- 🔑 Configure your OpenRouter API key
- 🖼️ Generate images with state-of-the-art models
- 🔄 Multi-model support: GPT-image-2, Flux, and more
- 🌐 Web-based interface

## Supported Models

| Model | Provider | Status |
|---|---|---|
| gpt-image-2 | OpenAI | ✅ Supported |
| More coming soon... | | |

## Getting Started

```bash
# Clone the repo
git clone https://github.com/JayLyu/openpix.git
cd openpix

# Install dependencies
npm install

# Set your OpenRouter API key
export OPENROUTER_API_KEY=your_key_here

# Start the server
npm start
```
